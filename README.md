# 文件传输

面向 ReMagic 的前台文件传输应用。设备显示 USB/Wi-Fi 地址、二维码和六位配对码；电脑或手机浏览器可批量上传书籍与壁纸，也可在 Paper Pro 与 Paper Pro Move 之间按勾选项同步。

## 边界

- 应用进入前台才监听端口，退到后台先关闭监听并轮换全部凭据。
- 书籍写入原版系统书库 `/home/root/.local/share/remarkable/xochitl`，上传时生成
  官方 UUID 文件和配套 metadata/content/local/pagedata。
- 壁纸写入 ReMagic 壁纸目录，但不会自动替换当前壁纸。
- 同名文件以版本时间决定新旧，较新版本替换旧版本；旧版进入保留30天的回收站。
- 设备同步使用局域网自动发现、首次六位验证码配对和端到端加密；同步项包括书籍、KOReader、文档设置、MagicPaper、壁纸和 AI 密钥，选择会保存在本机。
- 设备同步开始前会统计本次需要接收、发送和删除的文件数与总字节数；同步进度显示总进度和当前文件进度。
- 官方书库的 UUID 文件会在同步状态中按 metadata 的 `visibleName` 显示为书名，底层仍保留 xochitl UUID 文件身份。
- KOReader 先保存并关闭，再交换阅读进度、普通书签和普通应用数据；每本书的外观排版字段只有勾选“文档设置”才会同步。
- MagicPaper 同步前会请求系统完整关闭应用和后台服务，再同步新旧数据目录与配置目录。
- 同步只使用可路由的 Wi-Fi 局域网地址，忽略两台设备共有的 `10.11.99.1` USB 地址，避免误连回本机。
- 兼容旧 KOReader 适配层的空阅读历史 `{}`，接收后立即规范化为 `[]`；同步错误同时写入应用状态与 systemd journal。
- 书库扫描只接纳 xochitl 的 UUID 文档记录，壁纸只接纳 PNG；删除传播会先把目标文件移入保留30天的回收站。
- AI 密钥作为独立同步项处理，MagicPaper 普通配置不会夹带 `oracle.env`，接收后的密钥文件权限固定为 `0600`。
- 浏览器在本地把 JPEG/WebP 转成 PNG；设备端只接收并完整校验 PNG。

## 本地检查

```sh
./scripts/check.sh
```

## 构建

应用目前与相邻的 ReMagic 工作区共同开发，以路径依赖使用 `remagic-app-sdk`。正式发布时构建脚本会把 SDK 版本锁定到同一次 ReMagic 系统发布。
