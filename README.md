# 文件传输

面向 ReMagic 的前台文件传输应用。设备显示 USB/Wi-Fi 地址、二维码和六位配对码；电脑或手机浏览器可批量上传书籍与壁纸，也可在 Paper Pro 与 Paper Pro Move 之间同步。

## 边界

- 应用进入前台才监听端口，退到后台先关闭监听并轮换全部凭据。
- 书籍写入 ReMagic 与 KOReader 的统一书库 `/home/root/books`。
- 壁纸写入 ReMagic 壁纸目录，但不会自动替换当前壁纸。
- 同名文件以版本时间决定新旧，较新版本替换旧版本；旧版进入保留30天的回收站。
- 设备同步使用局域网自动发现、首次六位验证码配对和端到端加密；KOReader 先保存并关闭，再交换阅读进度和普通书签。
- 浏览器在本地把 JPEG/WebP 转成 PNG；设备端只接收并完整校验 PNG。

## 本地检查

```sh
./scripts/check.sh
```

## 构建

应用目前与相邻的 ReMagic 工作区共同开发，以路径依赖使用 `remagic-app-sdk`。正式发布时构建脚本会把 SDK 版本锁定到同一次 ReMagic 系统发布。
